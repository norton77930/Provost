# OpenSpec source guidance

Identify the change from explicit sources or project memory. Read relevant current
specs plus the delta, proposal/design/tasks and declared contextFiles, including
custom locations. Provost does not require a fixed CLI schema or version.

Blocked dependencies and native gates stay binding. Give each worker a bounded
brief with acceptance, dependencies, paths and resources; not the entire apply loop.
Main owns common progress. Archive does not prove acceptance: unfinished items need
current evidence and disposition. Follow moved sources to their replacements; a
missing source or older CLI field is not an empty task list or readiness proof.

Sync/archive mutations require task authority. A handoff alone does not authorize
them. Keep native identities; no shared Provost project config is required.
