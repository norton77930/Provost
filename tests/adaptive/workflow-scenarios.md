# Scenario evaluation

The workflows fixtures contain synthetic inputs and expected judgments. Unittest
checks fixture completeness only. For separately authorized live evaluation, give
each input and the adaptive policy to a Claude session without write/dispatch tools;
request verdict, source citations and brief reason. Compare manually with expected.
Record model, effort, CLI version and fixture revision. No paid probes have been
implied or performed by the fixture test. Do not report it as agent behavior proof.
